## Build integration

The build selects `pahole-commit` by default; the existing `PAHOLE_TAG`
override accepts an explicit tag or commit. Repository and requested ref
identify separate source/build directories, preserving the previous
checkout. The helper fetches an unavailable revision, checks out its
resolved commit, rejects tracked local edits, and uses source/recipe
identity to decide whether to reuse the installation.

A changed identity regenerates kernel/module BTF and reruns the selftests
build so generated headers and skeletons follow the new BTF. Installed and
packaged manifests retain source and build identities. Distro and runtime
workflow path filters include the new pin file.

The normal build passed and regenerated kernel/module BTF and selftests.
Installed kernel and all three modules match their build outputs. The
[version manifest](2026-09-07-version.txt) records the upstream commit and
build identity. The [reuse check](2026-09-07-reuse.log) leaves the binary
unchanged; the old patched checkout is [rejected without modification](2026-09-07-dirty-source.log).

The [standalone corpus](2026-09-07-corpus.log) passes with the same 991
inputs, 3,071 successes, 1,940 expected failure rows, five expected
processing failures and three expected open failures. The
[exact arena check](2026-09-07-arena.log) passes all 66 program expectations:
63 successes and three rejections. The [normal runtime check](2026-09-07-runtime.log)
for tracing, aggregate returns and kfunc calls reports 4/51 passes, two
compiler-dependent skips and no failures, including all four tracing
subtests.

The fresh [full sweep](2026-09-07-full.json) and [gate](2026-09-07-gate.log)
pass: **623 OK / 58 FAIL / 86 SKIP / 0 NORESULT**, 31 chunks and zero
host timeouts. Every recorded test status is identical to the kernel-pin
reference. The baseline pointer and exclusion policies are unchanged.
This isolated comparison used LLVM 22.1.8; the compiler upgrade is a separate change.
